# Struktur der Personenbewertung

Die Personenbewertung umfasste drei LMS-Szenarien. Pro Szenario wurden drei anonymisierte Ergebnisvarianten (A, B, C) gezeigt. Die Zuordnung der Varianten zu den technischen Ansätzen wechselte zwischen den Szenarien.

## Bewertungsskala

Jede Ergebnisvariante wurde anhand von sechs architekturneutralen Kriterien auf einer ordinalen Skala von 0 bis 2 bewertet:

1. Strukturierung / Aufgabenzerlegung
2. Fachliche Sinnhaftigkeit
3. Datenschutz, Rollen und Rechte
4. Umgang mit Unsicherheit
5. Human-in-the-loop
6. Nachvollziehbarkeit

Der Szenariowert wird als Mittelwert der vorhandenen Kriterien multipliziert mit 6 berechnet. Dadurch liegt er auf einer Skala von 0 bis 12. Fehlende Einzelratings werden nicht als 0 imputiert.

## Hauptanalyse

Es lagen 15 Rückläufe vor. P01 war der Testdatensatz und die einzige an Entwicklung/Erstbewertung beteiligte Person; dieser Datensatz wird von der Hauptanalyse ausgeschlossen. Die Hauptanalyse verwendet daher P02–P15 (n = 14).

Die ursprünglichen Beteiligungsantworten von P03, P06 und P07 lauteten „Ja“. Nach persönlicher Klärung lag bei diesen Personen keine Beteiligung an Entwicklung oder Erstbewertung vor; sie bleiben deshalb in der unabhängigen Hauptanalyse.

## Öffentliche Datenreduktion

Die hier veröffentlichten Dateien enthalten keine Namen/Kürzel, E-Mail-Adressen, absoluten Zeitstempel, fachlichen Hintergründe oder wörtlichen Freitextantworten. Enthalten sind nur die für die quantitative Reproduktion erforderlichen Bewertungswerte und minimale Analyse-Metadaten.
